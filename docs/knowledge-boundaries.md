# AIの認識・思考・行動境界

**Type:** philosophical-model  
**Status:** proposed  
**Scope:** Vibe AIの認識、思考、実行の境界を明示するための概念モデル

## 目的

AIに「わかったつもり」をさせない。AIが何を知らず、何を考慮せず、何を実行できず、何を実行してはならないかを区別する。

自己申告だけを能力や理解の証拠として扱わない。観測、実行結果、検証可能な証拠によって主張を評価する。

## 6つの境界

### 1. 知らないこと — Unknown

対象について必要な知識を持っていない状態。

確認すること:
- 何が不明なのか。
- 調査すれば判明する可能性があるか。
- 何を根拠に既知・未知を判断しているか。

「知らない」は「調べてもわからない」と同義ではない。

### 2. やるべきでないこと — Must not

規則、倫理、安全、権限、責任などの理由で実行してはならないこと。

確認すること:
- 何が禁止・制限の根拠か。
- 誰の権限や利益に影響するか。
- 停止、承認、または安全な代替策が必要か。

技術的に可能であることは、実行してよいことを意味しない。

### 3. やらないこと — Won't / Not doing

実行可能であり、禁止もされていないが、方針、優先順位、スコープ、または明示的な選択によって実行しないこと。

確認すること:
- 意図的に見送ったのか、未着手なのか、忘れているのか。
- 実行しない理由と影響は何か。
- 省略した作業が成果や安全性に影響しないか。

「やらない」と「やれない」を混同しない。未着手を、意図的な選択だったかのように後付けで説明しない。

### 4. やれないこと — Cannot do

現在の能力、道具、情報、権限、環境、時間などの制約によって実行できないこと。

確認すること:
- 具体的な障害は何か。
- 制約は技術的なものか、情報・環境・権限上のものか。
- 道具や条件を変えれば可能になるか。
- 実行した事実と、成功を確認した事実を区別できているか。

「コードを書いた」は「テストが通った」を意味しない。「試していない」は「できない」の証拠ではない。

### 5. 考えられないこと — Cannot think

現在の概念、情報、表現手段、推論能力などの制約により、適切に構想・推論・理解できないこと。

確認すること:
- 何が思考を制約しているか。
- 別の概念、表現、データ、視点を使えば考えられるか。
- 能力の限界を示す証拠があるか、それとも単に未検討なのか。

AIが「考えられない」と申告しただけで、原理的な不可能性が証明されたことにはならない。

### 6. 考えないこと — Not thinking

考える能力があるかどうかとは別に、対象を検討していない、または検討対象から外していること。

確認すること:
- どの前提や指示によって対象外になったか。
- 探索範囲、習慣、時間、優先順位の影響はあるか。
- 見落とした可能性を発見するため、別視点や反例による検討が必要か。

「考えない」は、能力不足ではなく、思考の選択や探索範囲の問題である場合がある。

## 調査可能性の追加分類

「知らないこと」を扱うときは、次の状態も区別する。

1. **調べればわかるが、まだ調べていない。** 情報や証拠が存在し、利用可能な方法で取得・検証できる可能性がある。
2. **調べても現時点ではわからない。** 情報がない、アクセスできない、観測できない、または検証手段がない。
3. **調べるべき対象だと気づいていない。** 未知そのものが問いや調査対象に含まれていない。
4. **所定の条件下では知り得ない。** 制約のもとで知識を獲得できない。現時点で不可能なことと、原理的に不可能なことは区別する。

## 運用原則

- **状態を混同しない。** 無知、禁止、選択、能力限界、思考限界、未検討を別々に記録する。
- **主張に証拠を求める。** 「わかった」「できる」「実行した」「検証した」という申告を、対応する証拠と照合する。
- **未知を探索する。** 前提、対象外にした条件、反例、境界条件、異なる立場からのレビューを用いて、認識されていない未知を発見する。
- **不可能性を安易に断定しない。** 現時点の制約と原理的な限界を分け、何が変われば可能になるかを記録する。
- **省略を隠さない。** 実施しなかった作業、未確認の条件、残る不確実性を明示する。
- **境界を更新する。** 新しい道具、情報、観測、実験結果によって分類を見直す。
- **権限と能力を分離する。** できることでも、許可されていなければ実行しない。

## 基本原則

> AIの能力境界を自己申告だけで決めない。知らないこと、やるべきでないこと、やらないこと、やれないこと、考えられないこと、考えないことを区別し、証拠に基づいて検証する。

> 目的は未知をゼロにすることではない。知らないことを知っていることにせず、未検討の領域を網羅済みと誤認せず、未知を発見する確率を高めることである。
