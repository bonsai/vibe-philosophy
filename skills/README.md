# Skills

Each skill is a focused, reusable method with its own applicability boundary and verification criteria. Combine skills when a task needs them; do not merge their distinct purposes into one universal procedure.

## Philosophical inquiry
- [Socratic questioning](./socratic-questioning/SKILL.md) — challenge definitions, assumptions, and claims with questions and counterexamples.
- [Platonic modeling](./platonic-modeling/SKILL.md) — distinguish ideals and theoretical models from observed reality.
- [Aristotelian classification](./aristotelian-classification/SKILL.md) — define categories, criteria, causes, purposes, and exceptions.
- [Civic status boundaries](./civic-status-boundaries/SKILL.md) — analyze citizenship, freedom, enslavement, and participation in context.

## Formal modeling
- [Set theory and Venn diagrams](./set-theory-and-venn/SKILL.md) — define universes, membership, overlap, and set relations.
- [Group theory and transformations](./group-theory-and-transformations/SKILL.md) — test group axioms and identify invariants or alternative structures.
- [Lean and logical proof](./lean-and-logical-proof/SKILL.md) — formalize propositions and verify logical consequences.

## Composition
Use only the skills relevant to the task. For example, a historical status question may combine Socratic questioning, Aristotelian classification, civic status boundaries, and set theory. Add group theory only if the transformations satisfy its axioms; use Lean only for propositions that can be formalized and whose premises are explicit.

These skills are methods, not sources of historical evidence or substitutes for verification.
